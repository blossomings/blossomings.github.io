The Letter C | Hard Sound - CA, CO, CU

Learning Objectives

By the end of this lesson, you will be able to
➧ Recognize the letter C.
➧ Pronounce the hard C sound correctly.
➧ Read the syllables CA, CO, and CU.
➧ Blend syllables to read simple Spanish words.
➧ Read short sentences using the hard C sound.
➧ Understand the first important rule for the letter C.

Introduction

Today you'll learn one of the most important letters in Spanish | C
The letter C has two different sounds.
Today we'll learn the hard C sound.
When C comes before A, O, or U, it sounds like the English K.






Pronunciation Guide
